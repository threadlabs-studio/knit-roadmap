# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/threadlabs-studio/knit-roadmap/security/advisories/new).

Do not open a public issue or discussion. Do not include real workspace content,
credentials, tokens, personal information, or access links in public artifacts.

Include a concise description, affected surface, reproduction steps using test
data, and potential impact. Threadlabs will acknowledge the report and coordinate
disclosure privately.

This public tracker does not contain Knit's source code, but private vulnerability
reports here are still routed to the product maintainers.
